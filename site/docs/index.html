개요

타 작품의 아트·이름을 복제하지 않고, 전투 설계 패턴만 참고합니다.

Survivor Arena는 Steam PC를 목표로 하되, GitHub Pages로 웹 플레이 테스트를 합니다. 조작은 WASD 이동 / 방향키 공격 / Space 대시(무적) / Q 무기 / E 액티브입니다.

하이브리드 방향: 뱀서의 물량·스폰 이벤트 + 아이작의 몹 아키타입 + 하데스의 텔레그래프·대시 전제 전투. 자동공격 전용이 아니라 수동 조준이 있으므로, “읽을 수 있는 위협”을 더 넣어도 됩니다.

뱀파이어 서바이벌

핵심은 개별 AI보다 스폰 디렉터와 맵 이벤트입니다.

물량웨이브이벤트
패턴동작플레이어 반응
웨이브 스케일 시간(분)마다 적 종류·밀도·스폰 간격 상승 빌드 스노우볼 vs 압박
Chase 잡졸 화면 밖에서 생성되어 플레이어로 추격 이동으로 딜 박스 유지

Wall / Circle 꽃·해파리 등이 원을 둘러쌈 돌파 또는 내부에서 딜

1차 몹 세트 제안

추격 잡졸만 있는 상태를 벗어나기 위한 최소 구성입니다.

  1. Grunt — 추격 접촉 (현재)
  2. Runner — 빠르고 체력 낮음 (스웜용)
  3. Shooter — 정지/저속 이동하며 탄 발사
  4. Bomber — 근접 자폭 (대시 리워드)
  5. Spawner — 고정 네스트 (우선 처치)
  6. Elite — 예고 돌진 또는 원형 휩쓸기 + 보상

웨이브 이벤트 3종 (우선):

  • Bat Swarm — 한 방향 돌진
  • Ring Wall — 둘러싸기 약 30초
  • Boss Drop — 처치 시 보상
